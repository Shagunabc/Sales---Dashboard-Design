# Sales---Dashboard-Design
This repository contains a simple interactive sales dashboard created using Power BI.

## Files Included
- `Superstore_Sales.csv`: The dataset used for analysis
- `Dashboard_Insights.txt`: Key insights from the dashboard
- `dashboard_screenshot.pdf`: Exported view of the dashboard
- `README.md`: Summary of the task and approach

## Tools Used
- Power BI for data visualization
- CSV file for dataset

## Summary
The dashboard shows sales performance by Region, Category, and Month. It includes line, bar, and donut charts, along with a slicer for filtering by region or category.
